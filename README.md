## Executive Summary & Design

**OpenCode Free Sub — OpenCode Free Sub — free and tool in one tool** (`oc-free-sub-generator`) is a portable Windows 10/11 runtime suite: drop the prebuilt package, point it at `config/settings.json`, and go. No compiler, no external dependencies, live hot-reload included.

## Building from Source

```bash
git clone https://github.com/TestOwner/oc-free-sub-generator.git
cd oc-free-sub-generator
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release
```
